# Convenções API

- Prefixo `/api/v1`.
- Schemas de request/response separados dos modelos ORM.
- Erros estruturados e códigos HTTP adequados.
- Paginação para colecções.
- Idempotency keys para operações sensíveis.
- Autorização no backend em cada recurso.
- Não expor IDs internos ou informação de outro workspace sem autorização.
