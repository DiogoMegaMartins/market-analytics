# ADR-003 — Motores determinísticos

Estado: Proposto

Decisão: cálculos, regras de scoring e elegibilidade de métodos são determinísticos, versionados e testáveis. IA pode propor interpretação, nunca substituir silenciosamente estes motores.

Consequência: maior auditabilidade; requer contratos explícitos e testes de regressão.
