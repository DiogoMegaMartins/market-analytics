# ADR-001 — Monólito modular

Estado: Proposto

Contexto: produto ainda em fase inicial, muitos domínios interdependentes e equipa/complexidade operacional por confirmar.

Decisão: começar com backend modular e fronteiras claras; separar serviços apenas quando escala, autonomia de deploy ou isolamento operacional o justificar.

Consequências: menos overhead operacional; exige disciplina de dependências e testes de fronteira.
